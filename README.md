# BloodJuice — Short Tutorial

A fast browser survival game built with React + TypeScript.

## 1) Run locally

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal (usually `http://localhost:5173`).

## 2) Core controls

- **Move:** `W/A/S/D` or Arrow keys
- **Aim:** Mouse / touch direction
- **Pause:** `Esc` (if enabled in your build)
- **Choose upgrades:** Click or tap when level-up/synthesis screens appear

## 3) First 2 minutes strategy

1. **Keep moving in circles** to avoid being boxed in.
2. **Prioritize one main weapon** early instead of splitting upgrades.
3. **Take survivability upgrades** (HP/regen/defense) if you are getting hit often.
4. **Save risky synthesis choices** until your build is stable.

## 4) Win condition mindset

- Survive waves by balancing **damage**, **mobility**, and **sustain**.
- If a run starts collapsing, kite enemies to reset spacing before re-engaging.

## 5) Quick troubleshooting

- If nothing appears, confirm your Node version is modern (18+ recommended).
- If controls feel laggy on mobile, reduce background apps and reload.

Have fun—optimize your weapon path and push deeper each run.
